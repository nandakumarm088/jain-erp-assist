Jain ERP Assist - by NK Developers

INSTALL IN CHROME
1. Extract this ZIP into a permanent folder.
2. Open chrome://extensions in Chrome.
3. Enable Developer mode.
4. Click Load unpacked and select the extracted folder containing manifest.json.
5. Pin Jain ERP Assist from the Extensions menu.
6. Sign into Jain ERP, open the attendance page, and click the extension icon.

Attendance changes must be reviewed and saved manually on the website.
The extension does not click the website Save button.
Your login, presets, and copied attendance are not included in this package.
This is an independent helper, not an official Jain extension.
