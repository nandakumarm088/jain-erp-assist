# Jain ERP Assist

Independent Jain ERP attendance helper by NK Developers. Not an official Jain extension.

This repository root is the unpacked extension for version 1.5.6. Download the repository as a ZIP, extract it, then load the extracted folder containing `manifest.json`.

## Chrome

Open `chrome://extensions`, enable **Developer mode**, choose **Load unpacked**, and select this folder.

## Microsoft Edge

Open `edge://extensions`, enable **Developer mode**, choose **Load unpacked**, and select this folder.

Supports Jain ERP Regular and Remedial attendance presets, attendance copy/apply, and marking students from pasted USNs. Review attendance changes and save manually on the website; the extension never clicks Save.
